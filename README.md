# Azure IT Support Lab
This project documents hands-on IT support tasks completed in Microsoft Azure, including virtual machine deployment, user administration, networking, troubleshooting, software support, and ticketing.

## Lab Tasks

1. Create Resource Group
2. Deploy Virtual Machine
3. Remote Into Virtual Machine
4. Create and Manage Local Users
5. Troubleshoot Network Connectivity
6. Manage Windows Updates
7. Additional IT Support Tasks
8. Software Installation and Troubleshooting - Part 1
9. Software Installation and Troubleshooting - Part 2
10. Troubleshoot Print Queue
11. Credential Manager and Cache Troubleshooting
12. Ticketing System - Part 1
13. Ticketing System - Part 2

## 01 - Create Resource Group

Created an Azure Resource Group named `RGLab01` in the East US region to organize and manage the resources used throughout this lab.
